# Height vs Weight Prediction using Linear Regression

## 📌 Project Overview
This project demonstrates the implementation of a simple Linear Regression model using Python and Scikit-learn. The model is trained on a dataset containing height and weight values to predict a person's weight based on their height.

## 🎯 Objective
- Understand the basics of supervised machine learning.
- Implement Linear Regression using Scikit-learn.
- Train and evaluate a predictive model.
- Visualize the relationship between height and weight.

## 📂 Dataset
The dataset contains two variables:
- **Height** (Independent Variable)
- **Weight** (Dependent Variable)

> Note: This dataset is used for educational purposes to understand the working of Linear Regression.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 🚀 Workflow
1. Import the required libraries.
2. Load and explore the dataset.
3. Separate the input and target variables.
4. Split the dataset into training and testing sets.
5. Train the Linear Regression model.
6. Make predictions on the test data.
7. Visualize the regression line.
8. Evaluate the model performance.

## 📈 Results
The model successfully learned the relationship between height and weight and can predict weight values for new height inputs.
